# Thing on a Spring: BIG ADVENTURE

A fan-made, expanded remake of the C64 game Thing on a Spring, played in the browser.

**It contains none of the original game's graphics, sound or data.** To play, you need your own copy of the original
Thing on a Spring (a disk image, zip, tape image or program file) and a password from the owner of this page. The
game builds its pictures and music from your copy, in your browser; nothing is uploaded anywhere.

Thing on a Spring (c) 1985 Gremlin Graphics. Music by Rob Hubbard. This is an unofficial fan project.
